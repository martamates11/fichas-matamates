Ecuaciones de segundo grado incompletas

Álgebra · Despejar x y sacar factor común

Nota: 0 / 10 Sin b: 0 / 5 Sin c: 0 / 5
Escribe tu nombre antes de continuar.
Cómo funciona · 1 punto por ecuación bien resuelta, 5 de cada tipo
  • Hay dos tipos de ecuaciones incompletas. Cambia de tipo con las pestañas.
  • Cada ecuación bien resuelta suma 1 punto. Cada tipo da como máximo 5 puntos: para sacar un 10 necesitas 5 bien de cada tipo.
  • Una ecuación está bien resuelta si aciertas todos sus pasos a la primera. Si fallas un paso, verás por qué y podrás terminarla para practicar, pero esa ecuación no suma. Los fallos no restan puntos.
  • Cuando consigues 5 bien en un tipo, ese tipo se cierra.
  • Escribe las soluciones como enteros, fracciones (3/2) o decimales (1,5). Para los negativos usa el signo -. Si la ecuación no tiene solución, pulsa «No tiene solución real».
  • Si usas «Mostrar soluciones», verás resuelta la ecuación en curso, pero esa ecuación no contará para la nota.

Recuerda

Sin término en x (b = 0)

Se despeja x².

ax² + c = 0 ▼ x² = −ca ▼ x = ± √−ca

Ojo: hay dos soluciones opuestas. Si x² sale negativo, no hay solución real.

Sin término independiente (c = 0)

Se saca factor común x.

ax² + bx = 0 ▼ x · (ax + b) = 0 ▼ x = 0  o  x = −ba

Ojo: nunca dividas entre x: perderías la solución x = 0.
