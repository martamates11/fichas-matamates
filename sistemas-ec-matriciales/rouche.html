📜 Recordatorio: teorema de Rouché-Frobenius y métodos de resolución

Sea un sistema de 3 ecuaciones con 3 incógnitas, con matriz de coeficientes A y matriz ampliada A* = (A | b). El sistema tiene solución si y solo si rg(A) = rg(A*).

RangosTipoSolucionesSe resuelve por
rg(A) ≠ rg(A*)SI · IncompatibleNinguna—
rg(A) = rg(A*) = 3 (n.º de incógnitas)SCD · Compatible determinadoÚnicaRegla de Cramer
rg(A) = rg(A*) < 3SCI · Compatible indeterminadoInfinitas (dependen de 3 − rg parámetros)Método de Gauss

Regla de Cramer (solo si |A| ≠ 0): x = |Ax| / |A|,  y = |Ay| / |A|,  z = |Az| / |A|, donde Ax es la matriz A con la columna de x sustituida por la columna de términos independientes (y lo mismo para y y z).

Para superar la ficha tienes que resolver bien un sistema de cada tipo: SCD, SCI y SI. No sabrás de qué tipo es hasta que lo discutas.
