Teorema de Rouché-Frobenius. Sea A la matriz de coeficientes, A* = (A | b) la matriz ampliada y n = 3 el número de incógnitas. El sistema tiene solución si y solo si rg(A) = rg(A*).

RangosTipoSoluciones
rg(A) ≠ rg(A*)SI · IncompatibleNinguna
rg(A) = rg(A*) = nSC · Compatible determinadoÚnica
rg(A) = rg(A*) < nSCI · Compatible indeterminadoInfinitas

Método. 1) Calcula |A| en función de m. 2) Resuelve |A| = 0: sus soluciones son los valores críticos. 3) Para los demás valores de m, |A| ≠ 0 y rg(A) = rg(A*) = 3. 4) En cada valor crítico, sustituye m y estudia los rangos con menores.

Menores. El rango es el orden del mayor menor no nulo. Si encuentras un menor de orden 2 no nulo en A, rg(A) ≥ 2. Para rg(A*), orla ese menor con la fila que falta y la columna de términos independientes: si ese determinante de orden 3 es ≠ 0, rg(A*) = 3; si es 0, rg(A*) = 2.

Para superar la ficha tienes que discutir bien un sistema de cada tipo: A (un valor crítico, incompatible), B (un valor crítico, compatible indeterminado) y C (dos valores críticos). No sabrás de qué tipo es hasta que lo discutas.
